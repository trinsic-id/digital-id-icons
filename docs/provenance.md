# Provenance

Digital ID Icons is an original visual system created for Trinsic in 2026.

## Authoring process

The work combined:

- human art direction, semantic decisions, selection, and revision;
- AI-assisted exploration of metaphors, confusion risks, SVG drafting, and blind visual evaluation; and
- deterministic editing of SVG geometry on a declared 24×24 grid.

The final SVGs are custom-drawn geometry for this project. They were not produced by copying path data from Lucide or another icon set. The work used the common 24×24, 2 px, round-cap conventions also used by Lucide and related outline icon systems so the icons can sit comfortably beside them.

The icons cannot be accurately described as either “hand-drawn” or “AI-generated” alone. Either would flatten the actual process.

## Third-party material
